🚀 NEXUS OS v1.0 – Arduino LCD Sci-Fi System

NEXUS OS to projekt wykorzystujący Arduino Uno R3 oraz wyświetlacz LCD 16x2. Jego celem jest stworzenie futurystycznego interfejsu komputerowego z animacjami inspirowanymi systemami science-fiction.

🖥️ Funkcje projektu
🚀 Animowany ekran startowy (BOOT SYSTEM).
⚡ Animacja ładowania systemu.
🟢 Efekt MATRIX z losowymi cyframi.
📡 Animacja skanowania radarem.
🤖 Animowana twarz robota.
🔐 Symulacja autoryzacji dostępu.
⏱️ Licznik czasu działania systemu.
💡 Migające podświetlenie LCD.
🔄 Automatyczne przełączanie animacji.

⚙️ Jak działa projekt?
1. Uruchamianie systemu

Po uruchomieniu Arduino wyświetla ekran powitalny NEXUS SYSTEM, a następnie rozpoczyna procedurę inicjalizacji.

2. Ładowanie

Na wyświetlaczu pojawia się animowany pasek postępu symbolizujący ładowanie systemu.

3. MATRIX

System generuje losowe cyfry na obu liniach wyświetlacza, tworząc efekt przypominający komputerowy terminal.

4. Radar

Animacja radaru symuluje skanowanie otoczenia.

5. Robot

Na ekranie pojawia się animowana twarz robota wykorzystująca własne znaki LCD.

6. NEXUS OS ONLINE

Po zakończeniu uruchamiania system przechodzi do głównego ekranu, wyświetlając status ONLINE i licznik czasu.
